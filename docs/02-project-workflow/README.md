
# 02 — Project Workflow

## Objective

Define the development workflow used to build EduGenie from model selection through local testing.

## Project Workflow

EduGenie was developed through four major milestones.

### Milestone 1 — Model Selection and Architecture

Selected the AI models and defined their responsibilities within the application.

### Milestone 2 — Core Functionalities Development

Implemented the five major learning features:

- Question and Answer
- Concept Explanation
- Quiz Generation
- Content Summarization
- Personalized Learning Path

### Milestone 3 — Frontend Development

Built the web interface using HTML and CSS and connected the interface to the FastAPI backend.

### Milestone 4 — Testing and Deployment

Ran EduGenie locally using FastAPI and Uvicorn and verified the application's major features.

## Development Flow

Model Selection
↓
Core AI Modules
↓
FastAPI Backend
↓
Web Interface
↓
Frontend-Backend Integration
↓
Local Execution
↓
Functional Testing

## Verification

The complete development workflow was implemented successfully, from AI model configuration and core module development to FastAPI backend integration, web interface development, and local execution.
